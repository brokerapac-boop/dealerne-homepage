## 고치는 방법 (AI에게 시키기)
1. ChatGPT의 Codex(또는 Claude Code)에 이 저장소를 연결합니다.
2. 바꾸고 싶은 것을 말로 시킵니다. 예: "dealerne.com 첫 화면 제목을 'OOO'로 바꿔 줘."
3. AI가 Pull Request(PR)를 만들면, PR 화면에 Netlify가 단 **미리보기 주소**를 눌러 확인합니다.
4. 괜찮으면 PR의 **Merge** 버튼을 누릅니다. 1~2분 뒤 실제 사이트에 반영됩니다.
5. 마음에 안 들면 Merge하지 않고 AI에게 다시 시키면 됩니다.

잘못 올라갔을 때는 병합된 PR 화면의 **Revert** 버튼으로 되돌립니다.
